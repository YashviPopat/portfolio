Selected work

SkyEye-Next

Counter-UAS perception · VLM reasoning
Request a walkthrough

An end-to-end aerial threat detection pipeline that knows when it doesn't know — and asks for help instead of guessing.

  • RTSP and thermal ingest → YOLO11 detector → Kalman/ByteTrack tracker → temporal motion features → threat policy → ROS 2 / PX4 bridge
  • A confidence-gated cascade escalates only ambiguous tracks — temperature-scaled calibration, class-flip detection, Mahalanobis OOD scoring on motion signatures — to a vision-language model, cutting VLM calls to once per track
  • Strict JSON verdicts with a fail-safe "human review" path, so the system never fabricates a classification
  • Live FastAPI operator dashboard: MJPEG streaming, fault-injection controls, and natural-language queries over track history via validated text-to-SQL
  • Dependability harness with a ground-truth sky simulator and 9 fault presets — 0.98 precision / 0.96 recall sustained across all faults, with 25 automated tests

Gujarat News Intelligence

Relevance engine · structured LLM output
View repository

A news scraper that doesn't ask "is this about Gujarat?" — it asks "could this be useful for Gujarat?"

  • Scrapes national and regional feeds, then scores every article against a structured Gujarat knowledge profile — climate, crops, economy, cities, departments, live programmes
  • A Maharashtra traffic-AI policy scores high (Ahmedabad has the same problem and the infrastructure to adopt it); a Kerala rubber subsidy scores near zero (semi-arid Gujarat grows cotton, not rubber)
  • Returns a strict JSON verdict per article: relevance type, domain, transferability reasoning, responsible departments, and 0–100 feasibility, benefit, urgency and cost scores
  • Degrades gracefully to a keyword heuristic with no API key, so the product still works end to end
